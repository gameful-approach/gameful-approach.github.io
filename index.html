        Export to Canvas

        Downloads a CSV in the format Canvas uses to import rubrics. It includes the descriptors shown above, with points split 4-3-2-1 across the levels.

        Canvas rubrics are criterion-by-level grids, so the file contains the analytic version of this rubric.

        How to import it into Canvas
        1. In your course, open Rubrics and select Import Rubric (Enhanced Rubrics).
        2. Upload the CSV. Don't open and re-save it in Excel first, which can change the formatting.
        3. Imported rubrics arrive as drafts. Open the rubric, check it, and select Save Rubric.
        4. Set the rating order and scoring options there; the file can't set them. Then attach the rubric to the assignment with Find Rubric.

        How to interpret the research base

        These are research-informed examples drawn from published course implementations or practice cases. Evidence quality varies. Most sources establish feasibility and disciplinary relevance, but do not establish scoring reliability across instructors or institutions. Pilot locally, align the rubric to the intended learning, and check scorer agreement before high-stakes use.

        AIAS descriptions follow the current AI Assessment Scale 2.1 (opens in a new tab). AIAS is a design aid, not evidence that a particular assessment is valid or reliably scored.
